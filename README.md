## 🧠 About

**Terminal Gambling** is an interactive command-line gambling simulation built from scratch with Python.

The project simulates simple games of chance using virtual credits, allowing players to place bets, test their luck, and manage their in-game balance.

This project is part of my **60-Day Python Project Challenge**, where I am building projects from scratch to strengthen my Python, problem-solving, and software engineering skills.

> ⚠️ **Note:** This project uses virtual credits only. No real money or financial transactions are involved.
